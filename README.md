# 사이트 반응 필터 (Site Reaction Filter)

🚀 **구글 검색 결과 속 사이트 반응, 이제 헤매지 말고 한눈에 확인하세요!**

정보를 찾다 보면 블로그나 광고성 글보다 실제 사용자들의 생생한 후기와 반응이 궁금할 때가 많습니다. '사이트 반응 필터'는 구글 검색 결과에서 특정 사이트의 링크만 추출하여 깔끔하게 정리해 주는 검색 보조 도구입니다.

## ✨ 주요 기능

- **실시간 사이트 필터링**: 구글 검색과 동시에 주요 사이트(GitHub, StackOverflow, OKKY, 디시인사이드, 더쿠, Reddit, 나무위키 등)의 게시글을 자동으로 찾아냅니다.
- **⚙️ 사이트 관리 (신규)**: 이제 사용자가 직접 원하는 사이트를 추가하거나, 기본으로 제공되는 사이트들을 끄고 켤 수 있습니다.
  - **커스텀 사이트 추가**: 도메인, 이름, 아이콘(이모지)을 지정하여 나만의 필터를 구성하세요.
  - **기본 사이트 토글**: 자주 보지 않는 기본 사이트는 리스트에서 숨길 수 있습니다.
- **세련된 사이드바 UI**: 검색 결과 우측에 플로팅 사이드바가 나타나 검색 흐름을 방해하지 않으면서 사이트 반응을 바로 확인할 수 있습니다.
- **사이드바 자유 이동 (Draggable)**: 사이드바 헤더나 최소화 버튼을 드래그하여 화면 원하는 위치로 옮길 수 있으며, 설정된 위치는 다음 검색 시에도 자동으로 유지됩니다.
- **사이트 내 검색 (Site Search)**: 직접적인 검색 결과가 없더라도, 클릭 한 번으로 해당 사이트 내의 'Google site:' 검색을 수행할 수 있습니다. 이미 사이트 검색 중이라면 기존 필터를 제거하고 새 사이트로 깔끔하게 전환됩니다.
- **사용자 맞춤형 설정**: 사이드바 자동 열기 여부, 사이트 관리 섹션의 접힘 상태 등을 브라우저에 저장하여 사용자 취향에 맞게 유지합니다.
- **가볍고 안전함**: 외부 API 호출 없이 현재 페이지의 데이터만 활용하므로 빠르고 안전합니다.

## 🍱 기본 지원 사이트

- **개발/기술**: 🐈‍⬛ GitHub, 📚 StackOverflow, 💙 OKKY
- **국내 일반**: 🌳 나무위키, 🎮 디시인사이드, ✨ 더쿠, 💰 뽐뿌
- **해외**: 🤖 Reddit (레딧)

## 💡 사용 방법

1. 확장 프로그램을 설치합니다.
2. 구글에서 키워드를 검색합니다.
3. 우측 사이드바에 나타나는 사이트 게시글들을 확인하세요!
4. 사이드바 하단의 **'⚙️ 사이트 관리'**를 클릭하여 나만의 필터 리스트를 만들어 보세요.
5. '자동 열기' 토글로 사용자 편의에 맞게 조정하세요.

## 📦 설치 방법

1. 이 저장소를 로컬 환경에 다운로드하거나 클론합니다.
2. Google Chrome 브라우저를 엽니다.
3. 주소창에 `chrome://extensions/`를 입력하여 확장 프로그램 관리 페이지로 이동합니다.
4. 우측 상단의 **'개발자 모드'**를 활성화합니다.
5. **'압축해제된 확장 프로그램을 로드합니다'** 버튼을 클릭합니다.
6. 다운로드한 프로젝트 폴더( `manifest.json` 파일이 있는 위치)를 선택합니다.

## ✅ 최근 업데이트 (v1.2.0)

- **커스텀 사이트 관리 기능**: 사용자가 직접 필터링할 사이트를 추가/삭제할 수 있는 기능이 도입되었습니다.
- **기본 사이트 On/Off 토글**: 기본 리스트에 있는 사이트들을 개별적으로 비활성화할 수 있습니다.
- **UI 구조 개편**: 사이트 관리 섹션을 접고 펼 수 있도록 개선하고, 목록이 길어질 경우를 대비해 내부 스크롤을 적용했습니다.
- **네이밍 통일**: 모든 UI와 코드 내의 명칭을 '커뮤니티'에서 '사이트'로 변경하여 의미를 더 명확히 했습니다.
- **편의성 개선**: 커스텀 사이트 추가 시 랜덤 아이콘 추천 기능, 엔터 키 입력 지원, 중복 도메인 체크 로직이 추가되었습니다.

## 💻 기술 스택

- **Core**: JavaScript (Vanilla JS), CSS
- **Platform**: Chrome Extension API (Manifest v3)
